# Frontend

React + TypeScript + Vite + Tailwind CSS. See the [root README](../README.md)
for the full project overview, architecture, and setup instructions covering
both this and the backend.

## Quick start

```bash
npm install
cp .env.example .env
npm run dev      # http://localhost:5173, expects the backend on :4000
```

## Scripts

| Command | Does |
|---|---|
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Type-check (`tsc -b`) then production build |
| `npm run lint` | Run oxlint |
| `npm run preview` | Preview the production build locally |
